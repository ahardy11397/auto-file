## idea ##
and automated files sorting system using laya and local llms to auto scan, name and sort files based on a given set of criteria.

Identify the file type, use laya to decide what tool to use to scan the file, then scan the file and create a description of the file, use the description to name the file, use laya to decide where it should go based on the name and a predefined folder structure, move the file.

Log every step and change and movement

Everything must be able to run locally with nothing leaving the machine
